Under the hood

A clean three-layer stack.

Layer 1 · AppiOS
SwiftUIMapKitMKLocalSearchCompletersupabase-swift
Native maps and live anchor-search. Gathers structured input, renders results — never computes the ranking or holds secrets.
Layer 2 · DataSupabase
PostgreSQLPostGISRow-Level Securitysearch RPC
The single source of truth. Geolocation runs here — PostGIS turns 1,432 OpenStreetMap polygons into deterministic place tags. All matching happens in one server-side SQL function, behind RLS.
Layer 3 · PipelineIngest & Enrich
TypeScript / NodeGoogle PlacesClaude SonnetOpenStreetMap · Overpass
Run rarely, from a trusted machine. Pulls real places, tags vibe once with AI, derives geo features from OSM — every API key off users' devices.

Geolocation: Google gives exact coordinates; OpenStreetMap polygons add "is this on the water?" via PostGIS; MapKit renders it natively — and proximity is computed inside Postgres at query time.
