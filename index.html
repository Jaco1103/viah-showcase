Under the hood

A clean three-layer stack.

Layer 1 · AppiOS
SwiftUIMapKitMKLocalSearchCompletersupabase-swift
Native maps and live anchor-search. The app gathers structured input and renders results — it never computes the ranking or holds secrets.
Layer 2 · DataSupabase
PostgreSQLPostGISRow-Level SecurityAuthsearch RPC
The single source of truth. Geolocation runs here — PostGIS turns 1,432 OpenStreetMap polygons into deterministic place tags (waterfront, beach access). All matching happens in one server-side SQL function, behind RLS.
Layer 3 · PipelineIngest & Enrich
TypeScript / NodeGoogle PlacesClaude SonnetOpenStreetMap · Overpass
Run rarely, from a trusted machine. Pulls real places, tags their vibe once with AI, and derives geo features from OSM — keeping every API key off users' devices.

The geolocation story: places come from Google with exact coordinates; OpenStreetMap polygons add "is this on the water?" via PostGIS; MapKit renders it all natively — and proximity is computed inside Postgres at query time.
